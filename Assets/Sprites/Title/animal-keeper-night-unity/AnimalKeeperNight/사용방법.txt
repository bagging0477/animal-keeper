Animal Keeper — 밤 타이틀 화면

기존 낮 버전과 동일한 구성의 밤 변형입니다.
남색 하늘, 달과 별, 어두운 초록 풍경, 노란 트럭의 전조등을 추가했습니다.
하얀 글자/노란 테두리 로고와 트럭 추적 전환, 배경 시차 이동, 바퀴와 먼지 연출을 유지했습니다.

1. 가장 간단한 적용
압축을 풀고 AnimalKeeperNight 폴더 전체를 Assets 안에 넣으세요.
빈 씬 또는 별도 타이틀 씬을 열고 Create Empty로 빈 오브젝트를 만드세요.
AnimalKeeperNight.cs를 그 오브젝트에 붙이세요.
Play를 누르면 자동으로 Canvas와 그림을 생성합니다.
컴파일 후 Play 전에는 그림이 배치되지 않는 것이 정상입니다.
PNG를 수동 배치하거나 Camera를 트럭에 연결할 필요가 없습니다.
기존 낮 타이틀을 만든 오브젝트는 꺼두세요. 두 스크립트를 동시에 켜면 화면이 겹칩니다.
이 ZIP은 .unitypackage가 아니므로 Import Package로 열지 마세요.

2. 낮 버전과 독립된 파일
AnimalKeeperNight.cs와 Resources/AnimalKeeperNight 경로를 사용합니다.
기존 AnimalKeeperTitle.cs 및 Resources/AnimalKeeperTitle은 변경하지 않았습니다.
낮/밤 세트를 모두 보관하고 씬에서 사용할 세트 하나만 활성화하세요.
Resources 폴더와 하위 파일명은 바꾸지 마세요.

3. 연출 조절
Truck Speed 52: 이동 속도.
Follow Delay 2.3: 트럭을 따라가기 시작하는 시간(초).
Follow Blend Duration 1.5: 추적 속도가 부드럽게 올라가는 시간.
Wheel Frames Per Second 8: 바퀴 프레임 변경 속도.
Enable Dust / Enable Bounce: 먼지와 작은 흔들림 표시.
로고와 달/별은 고정, 구름/언덕/나무/도로는 거리별 속도로 움직입니다.
전조등은 픽셀 PNG를 트럭과 함께 움직이는 방식이며, 실제 URP Light 2D나 실시간 조명은 아닙니다.
스크립트는 UI의 크기와 위치로 추적 시점을 연출하므로 Cinemachine은 필요하지 않습니다.

4. 화면과 이미지 설정
원본 레이아웃은 480×300(16:10), 미리보기 PNG는 1440×900입니다.
Game 창에서 16:10 또는 960×600처럼 정수 배율 해상도를 권장합니다.
다른 화면 비율은 원본 비율을 유지하고 여백이 생깁니다.
카메라 배경색을 #14213D로 맞추면 여백과 잘 어울립니다.
전용 Editor 스크립트가 포함 경로의 PNG를 Point/압축 없음/밉맵 없음/Clamp로 설정합니다.
UI RawImage로 표시하므로 Texture Type Default를 유지하세요. Sprite PPU 설정은 필요하지 않습니다.
플랫폼 Texture Override로 압축/축소가 적용되어 있다면 따로 확인하세요.
흐리게 보이면 Resources/AnimalKeeperNight의 PNG를 선택해 Reimport하세요.
이 화면은 HUD/UI이므로 월드 동물의 PPU 규칙과는 별개입니다.

5. 들어 있는 파일
animal-keeper-night-preview.png: 정지 미리보기, 1440×900.
animation-preview.html: 브라우저에서 열어 애니메이션 확인. Unity에 HTML을 넣을 필요는 없습니다.
Resources/AnimalKeeperNight/: 하늘, 구름, 언덕, 나무, 도로, 점선, 풀꽃, 로고, 트럭2장, 전조등 PNG 12장.
AnimalKeeperNight.cs: 유니티 실행 시 자동 배치와 연출.
Editor/AnimalKeeperNightTextureImporter.cs: 이미지 임포트 설정.

6. 기존 시작 버튼 사용
자동 생성 Canvas의 Sort Order는 0입니다.
기존 버튼 Canvas를 Sort Order 10 이상으로 두면 그 위에 표시할 수 있습니다.
버튼과 씬 이동 기능은 포함하지 않았습니다.
이미지는 Raycast Target이 꺼져 있어 버튼 클릭을 막지 않습니다.
Unity UI(uGUI)가 프로젝트에 있어야 합니다.

7. 검증 범위
원본 도트 렌더링의 정지 화면, 세 시점의 실행, PNG 크기와 투명 채널, ZIP 구성을 확인했습니다.
기존 타이틀과 별개의 클래스/Resources 경로를 사용하도록 확인했습니다.
Unity Editor가 없어 컴파일 및 Play 테스트는 수행하지 않았습니다.
