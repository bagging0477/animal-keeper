Animal Keeper — 체력바 / 스테미나 바 Unity UI 세트

■ 무엇이 들어있나요?
붉은 체력바, 노란 스테미나 바, 하트/번개 아이콘, 빈 공통 프레임 PNG.
자동 배치 스크립트와 픽셀 이미지 자동 설정 스크립트.
앞서 승인한 이미지에서 바/아이콘을 분리해 작은 PNG로 정리했습니다.
다섯 상태 이미지를 바꿔 끼우는 방식이 아닙니다. 고정 프레임 위의 색 영역을 0~100%로 자릅니다.
0%, 12%, 63%, 100% 등 임의의 값을 표현할 수 있습니다.
프레임/아이콘은 고정되고 색 부분이 오른쪽부터 줄어듭니다.
숫자는 유니티 기본 글꼴로 표시하며, 원본 이미지의 도트 글꼴과는 다릅니다.

■ 1. 적용: 가장 간단한 방법
1) ZIP 압축을 해제합니다.
2) AnimalKeeperHUD 폴더 전체를 유니티 Project 창의 Assets 안으로 드래그합니다.
   Assets/AnimalKeeperHUD/AnimalKeeperHUD.cs 형태가 되어야 합니다.
3) 컴파일이 끝날 때까지 기다립니다.
4) Hierarchy에서 우클릭 > Create Empty를 선택하고 이름을 HUDManager로 바꿉니다.
5) HUDManager Inspector에 AnimalKeeperHUD.cs를 드래그해서 붙입니다.
6) Play를 누릅니다. 화면 왼쪽 위에 체력바와 스테미나 바가 자동으로 생성됩니다.
PNG를 따로 배치하거나 Canvas를 미리 만들지 않아도 됩니다.
Play 전에는 UI가 보이지 않고 Play 종료 시 생성된 UI는 사라집니다.
이 ZIP은 .unitypackage 형식이 아니므로 Import Package 메뉴를 사용하지 않습니다.

■ 2. 0~100% 테스트
Play 중 HUDManager를 선택하세요.
Health Percent: 체력 0~100. 기본값 100.
Stamina Percent: 스테미나 0~100. 기본값 100.
슬라이더를 움직이거나 숫자를 직접 입력하세요.
100은 가득 찬 상태, 0은 색 부분이 완전히 사라진 상태입니다.
Smooth Changes가 켜져 있으면 목표값까지 부드럽게 이동합니다.
즉시 바뀌게 하려면 Smooth Changes를 끄세요.
Change Speed: 초당 변하는 퍼센트 양. 기본 180.
컴포넌트 제목 우측 메뉴(점 3개)에서 Demo 100 to 0 (Play Mode)를 선택하면 5초 동안 두 바가 줄어듭니다.
Restore Both to 100 (Play Mode)를 선택하면 두 바를 회복합니다.
Play 중 바꾼 Inspector 값은 Play 종료 시 원래 값으로 돌아갑니다.
화면 숫자는 바의 현재 표시량을 반올림한 값입니다. 내부 fill 값은 연속적인 비율입니다.

■ 3. 실제 플레이어 체력과 연결
이 세트는 UI 표시를 담당합니다. 피해/회복/스테미나 소모/자동 회복 규칙은 기존 게임 코드에서 처리하세요.
기존 플레이어 스크립트에 아래 필드를 추가합니다.

[SerializeField] private AnimalKeeperHUD hud;

Inspector에서 HUDManager를 이 필드에 드래그하세요.
체력이 바뀌는 곳에서 아래처럼 호출하세요.

hud.SetHealth(currentHealth, maxHealth);
hud.SetStamina(currentStamina, maxStamina);

예: hud.SetHealth(75f, 100f);   // 75%
예: hud.SetHealth(150f, 200f);  // 역시 75%
예: hud.SetStamina(30f, 60f);  // 50%
퍼센트를 직접 넣을 수도 있습니다.

hud.SetHealthPercent(63f);
hud.SetStaminaPercent(12f);

SetHealth/SetStamina의 최대값이 0 이하이면 0%로 표시합니다.
최대보다 큰 값이나 음수는 0~100 범위로 제한됩니다.
Set... 메서드 호출은 동작 중인 데모 재생을 종료합니다.
연결 예제에서 currentHealth/maxHealth 등의 이름은 자신의 프로젝트 변수명으로 바꾸세요.
이 코드는 기존 체력 스크립트를 자동으로 찾아 연결하지 않습니다.

■ 4. 위치와 크기
Top Left Offset: 왼쪽/위쪽에서 떨어진 거리. 기본 (24,24).
Hud Scale: 전체 UI 배율. 기본 1. 더 크게는 1.5, 더 작게는 0.75.
Canvas 기준 해상도는 1280×720이고 화면 너비에 맞춰 자동 확대/축소됩니다.
Canvas Sort Order는 20입니다. 다른 UI와 겹치면 기존 Canvas 정렬 값을 확인하세요.
Scene의 카메라 위치나 Orthographic Size는 이 UI에 영향을 주지 않습니다.
이 세트는 클릭 기능이 없어 EventSystem이 없어도 표시됩니다.
HUDManager의 Scale은 (1,1,1)을 유지하고 크기는 Hud Scale로 조절하세요.
생성된 UI를 Play 중 직접 바꾸면 다음 프레임에 자동 설정이 다시 적용될 수 있습니다.

■ 5. 이미지 설정
Editor/AnimalKeeperHUDImporter.cs가 포함된 PNG에 다음 설정을 적용합니다.
Texture Type: Default
Filter Mode: Point
Compression: None
Generate Mip Maps: Off
Wrap Mode: Clamp
Read/Write: On
Non Power of 2: None
Alpha Is Transparency: On
자동 스크립트는 텍스처에서 실행 중 Sprite를 만듭니다. Default 설정을 유지해도 됩니다.
이미지가 이상하다면 Resources/AnimalKeeperHUD 안의 PNG 다섯 장을 선택하고 우클릭 > Reimport하세요.
Resources/AnimalKeeperHUD 폴더와 PNG 이름은 바꾸지 마세요.

■ 6. 자동 배치 대신 기존 UI에서 쓰기
PNG를 직접 쓰려면 Texture Type을 Sprite (2D and UI), Sprite Mode Single로 설정하세요.
단, 자동 Importer가 다시 Default로 바꾸므로 직접 사용할 복사본은 Resources/AnimalKeeperHUD 밖의 별도 폴더에 두세요.
빈 프레임을 UI Image로 놓고 내부에 fill 이미지를 올리세요.
프레임 원본 128×32 기준 내부 fill 위치: 왼쪽 9, 위 8, 너비 110, 높이 14.
fill Image의 Type은 Filled, Fill Method는 Horizontal, Fill Origin은 Left로 설정하세요.
fillAmount=0은 0%, fillAmount=1은 100%입니다. frame 전체에는 Filled를 적용하지 마세요.
자동 배치 방식과 직접 배치 방식 중 하나만 사용하면 됩니다.

■ 7. 파일 구성
AnimalKeeperHUD.cs — 자동 UI 생성 / 체력·스테미나 표시 / 테스트 기능
Editor/AnimalKeeperHUDImporter.cs — 에디터 PNG 설정
Resources/AnimalKeeperHUD/bar-empty.png — 빈 공통 프레임 128×32
Resources/AnimalKeeperHUD/hp-fill.png — 붉은 fill 110×14

Resources/AnimalKeeperHUD/heart.png — 하트 28×28
Resources/AnimalKeeperHUD/lightning.png — 번개 24×32

■ 8. 문제 해결
UnityEngine.UI 오류: Package Manager에서 Unity UI(uGUI / com.unity.ugui)가 설치돼 있는지 확인하세요.
Nothing shows: HUDManager와 스크립트가 활성화됐는지, Play 상태인지, Console에 오류가 있는지 확인하세요.
Missing HUD texture: Resources 경로/파일명과 중복 경로 여부를 확인하세요.
Sprite.Create/읽기 오류: PNG를 Reimport하고 Read/Write가 켜졌는지 확인하세요.
숫자나 바가 가려짐: 다른 Canvas의 Sort Order를 확인하세요.
두 세트가 겹침: AnimalKeeperHUD 컴포넌트는 한 개만 사용하세요.
값이 계속 다시 바뀜: 기존 스크립트가 매 프레임 Set...를 호출하는지 확인하세요.
빈 프레임만 줄어듦: 자동 배치 대신 직접 구성 중이라면 Filled 설정을 색 영역 Image에만 적용하세요.
프로젝트에 asmdef가 있으면 해당 어셈블리의 Unity UI 참조가 필요할 수 있습니다.

■ 검증 범위
PNG 크기와 분리 결과, 0~100 비율 계산, ZIP 무결성을 확인했습니다.
유니티 에디터가 이 환경에 없어 에디터 컴파일/Play 테스트는 수행하지 않았습니다.
