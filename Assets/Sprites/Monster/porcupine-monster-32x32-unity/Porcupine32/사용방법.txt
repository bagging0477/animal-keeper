호저 터렛 몬스터 — Unity용 32×32 스프라이트

1. 구성
Frames/: 상태별 개별 PNG 18장, 실제 크기 32×32.
porcupine-atlas-128x224.png: 4열×7행 아틀라스, 128×224.
validation.json: 각 프레임의 위치, 색 수, 불투명 영역 기록.
배경은 투명이며 그림자와 지면은 포함하지 않았습니다.
불투명 색상은 프레임당 최대 8색, 알파는 0/255만 사용합니다.
외곽선은 #2F2F2E입니다.

2. 프레임 구성 (행마다 왼쪽부터 오른쪽)
1행 idle-01~04: 대기 4장.
2행 walk-01~04: 이동 4장.
3행 raise-01~03: 발사 예고/가시 세우기 3장. 마지막 칸은 투명.
4행 shoot-01~03: 가시 발사 3장. 마지막 칸은 투명.
5행 hurt-01: 피격 1장. 나머지 칸은 투명.
6행 fallen-01: 쓰러짐 1장. 나머지 칸은 투명.
7행 quill-01~02: 별도로 날릴 가시 탄환 2장. 나머지 칸은 투명.
탄환은 32×32 프레임 안에 약 8×2 도트로 배치돼 있습니다.
기본 방향은 모두 오른쪽입니다. 왼쪽은 SpriteRenderer의 Flip X로 표현하세요.

3. 가장 간단한 Unity 적용
ZIP을 압축 해제하고 Porcupine32 폴더를 프로젝트의 Assets 안으로 드래그하세요.
Frames 안의 PNG를 전부 선택한 뒤 Inspector에서 다음을 설정합니다.
Texture Type: Sprite (2D and UI)
Sprite Mode: Single
Pixels Per Unit: 32 (실제 최종 오브젝트 배율 2 기준)
Filter Mode: Point (no filter)
Compression: None
Generate Mip Maps: Off
Pivot: Center (0.5, 0.5)
Apply를 누르세요.
ZIP은 .unitypackage 형식이 아니므로 Import Package로 여는 방식이 아닙니다.

4. 도트 크기 기준
이 프로젝트의 기준은 원본 1도트 = 월드 1/16칸입니다.
PPU = 16 × 실제 최종 오브젝트 배율을 사용하세요.
배율 2라면 PPU 32, 배율 1이라면 PPU 16입니다.
부모 Transform의 배율도 포함해야 합니다.
1080p에서 약 6px로 보이는지는 카메라 설정과 화면 배율까지 맞춰 늑대와 나란히 확인하세요.
프레임 크기 자체를 늘려서 도트를 맞추지 마세요.
발 기준 피벗은 변경하지 않았습니다.

5. Animation 클립 만들기
동일한 상태의 PNG를 이름순으로 선택해 Scene에 드래그하면 애니메이션 클립을 만들 수 있습니다.
기존 몬스터에 적용할 경우 기존 Animator에 상태별 클립을 연결하세요.
권장 시작값:
- 대기: 4~6 fps, Loop 켜기.
- 이동: 6~8 fps, Loop 켜기.
- 가시 세우기: 6~8 fps, Loop 끄기. 마지막 프레임을 원하는 예고 시간 동안 유지.
- 발사: 10~12 fps, Loop 끄기.
- 피격/쓰러짐: 각 1장 고정.
- 탄환: 8~12 fps로 2장을 반복하거나 한 장만 사용해도 됩니다.
공격 예고와 재장전 시간은 실제 게임 난이도에 맞춰 정하세요.

6. 아틀라스 사용 (개별 PNG와 둘 중 하나만 선택)
porcupine-atlas-128x224.png를 선택하고 Sprite Mode를 Multiple로 바꾸세요.
Sprite Editor > Slice > Grid By Cell Size에서 X32, Y32로 분할하세요.
Pivot Center, Apply.
투명한 빈 칸은 애니메이션에 포함하지 마세요.
나머지 Point/압축 없음/PPU 설정은 개별 PNG와 같습니다.
Sprite Editor가 없으면 프로젝트에 2D Sprite 패키지가 설치돼 있는지 확인하세요.

7. 터렛 공격 연결
캐릭터 발사 프레임에는 날아가는 탄환을 합쳐 그리지 않았습니다.
가시 탄환 PNG를 별도 SpriteRenderer 오브젝트로 만든 뒤 프로젝트의 투사체 로직에 연결하세요.
탄환의 이동 속도, 충돌 판정, 플레이어 피해량은 기존 게임 코드에서 처리해야 합니다.
발사 클립의 적절한 프레임에 Animation Event를 배치해 기존 발사 함수를 호출하는 방식으로 연결할 수 있습니다.
탄환의 프레임 여백까지 콜라이더로 잡지 말고 실제 가시 크기에 맞춰 설정하세요.
터렛을 완전히 고정형으로 쓴다면 이동 클립은 사용하지 않아도 됩니다.

8. 검증 범위
PNG 크기, 18개 프레임, 행별 빈 칸, 프레임당 최대8색, 알파0/255, ZIP 무결성을 확인했습니다.
게임 AI, Animator Controller, 프리팹, 피해/발사 스크립트는 포함하지 않았습니다.
Unity Editor 실행 테스트와 실제 게임 카메라에서의 외형/타이밍 검토는 하지 못했습니다.
