# 숲 방 - 2칸 폭 돌길이 고리 세 개로 이어져 막다른 곳이 없고, 길 사이를 나무/덤불이 빽빽하게 채운다.
# 동/서 가장자리는 위아래로 곧게 뻗은 2칸 폭 숲 가장자리 길이라, 이웃 방이 어느 높이에 붙어도 막히지 않는다.
# 남/북 가장자리 가운데에는 폭 4칸 돌길 입구가 있다(양옆은 나무/덤불). 격자 맵에서 위아래 방과 이어지는 자리라 막지 않는다.
# 고친 뒤 Unity 메뉴 Tools > Village Rooms > Build Room Prefabs 로 다시 만든다.
#
# 맨 아래 줄 맨 왼쪽 칸 = 방 로컬 칸 (-1, -1). 동/서 가장자리 열은 y -1..5(아래 7줄)를 반드시 포함하고, 끝 2열에는 장애물을 두지 않는다.
# 바닥 윤곽은 3칸 단위 이상으로만 들쭉날쭉하게 둔다(폭 1~2칸으로 튀어나온 칸은 검증에서 오류).
# 바닥:  . 잔디   : 돌길   ~ 바닥 없음
# 막힘:  T 나무1  Y 나무2  B 덤불  R 바위  G 묘비  C 십자가  S 높은 비석  K 받침 묘비  U 항아리  W 낮은 돌담  O 큰 바위(2×2)
# 장식:  , 잡초   r 자갈   b 작은 덤불   ; 길 위 자갈   (콜라이더 없음 - 지나갈 수 있고 스폰 가능 칸으로 센다)
