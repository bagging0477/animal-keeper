[1. 색 보정안] RV_recolor.png (420x420, RV.png와 같은 크기·같은 조각 위치 → RV.png.meta 그대로 쓸 수 있음)
  모양·크기·도트는 그대로, 색만 바꿈. 시트 전체(같은 차 8방향)를 같은 팔레트로 보정.
  - 외곽선: 투명과 4방향으로 닿은 가장자리 1픽셀을 #2F2F2E로. 아주 어두운 색(V<0.12)도 #2F2F2E로.
  - 색 줄이기: 가중 k-평균 20색(시트 전체 20색, 마을에서 쓰는 RV_2 조각 17색). 앞유리 푸른색(색조 190~260°, 채도 0.12 이상)은 회색에 묻히지 않게 따로 3색으로 묶음.
  - 채도: 팔레트 채도에 같은 배율(x0.79)을 곱해 RV_2 칠한 색 평균 채도(외곽선·V<0.25 제외)를 0.329 → 0.261로. 색조·명도는 그대로.
    흰 면적이 넓어 평균은 기준에 맞지만, 연두색 지붕 자체는 채도 0.53~0.56으로 남음(레서판다 0.51 정도).
  - RV_2 색 수 637 → 17, 반투명 픽셀 원본·보정안 모두 0.
  주의
  - RV.png.meta는 압축이 켜져 있어(textureCompression 1, DXT5) 그림만 바꾸면 렌더에서 색이 다시 흐트러짐(RV 영역 렌더 고유 색: 원본 376, 보정안·압축 켬 201, 보정안·압축 끔 21).
    줄인 색을 그대로 보이려면 적용할 때 RV.png.meta 기본 플랫폼 textureCompression 1 → 0이 필요(클래스 그림과 같은 처리).
  - VillageScene의 TruckPoint SpriteRenderer 색이 (0.72, 0.72, 0.72)라 게임에서는 RV가 72% 밝기로 보임(외곽선도 #2F2F2E보다 어둡게). 원본도 같은 조건.
  - 앞유리 가운데는 원본보다 어두운 남색(#404953)이 됨.
  RVShell.png(트럭 안, 자체 제작)는 손대지 않음.

[2. 도트 크기 4.8px → 6px 방법] (적용하지 않음, 고르지 않음)
  지금: RV_2 38x97텍셀, PPU 100 x 배율 5 → 텍셀 0.05칸 = 화면 4.82px, RV 크기 1.90x4.85칸.
  충돌체 BoxCollider2D 0.36x0.93(로컬) x 배율 5 = 1.80x4.65칸. 맵 생성기는 이 충돌체 x 배율로 트럭 크기(GetTruckFootprintSize)를 잼.
  A. 화면에서 1.25배 크게(TruckPoint 배율 5 → 6.25, VillageScene)
     - 도트 6.03px. RV 2.38x6.06칸.
     - 충돌체도 같이 커짐 2.25x5.81칸 → 트럭 자리 고르기(여유 2.5칸/변)가 좁은 방에서 더 자주 최소 여유(1.1칸)로 물러남, 트럭 주변에서 치우는 장애물·스폰 금지 칸·NavMesh 카버가 커짐,
       플레이어 스폰 칸 재선택 조건이 바뀜 → 같은 시드의 맵·스폰 결과가 달라짐(LinearRegressionDump·GridMapAudit 7a/7b 다시 확인 필요).
     - TruckPoint 상호작용 거리 2.7칸(중심 기준)이 RV 앞뒤 반 길이(2.9칸)보다 짧아져 앞·뒤에서는 탈 수 없게 됨 → 거리 조정 필요.
     - 바뀌는 파일: VillageScene(+ 상호작용 거리). 그림 그대로.
  A'. 1.25배 크게 + 충돌체 크기만 1/1.25로(0.288x0.744) → 트럭 크기 계산·맵 결과는 그대로, 그림만 커져 주변 장애물 그림과 더 겹쳐 보일 수 있음. 상호작용 거리 문제는 A와 같음.
  B. 6px 도트로 다시 찍기(크기 그대로)
     - 1.90x4.85칸을 6px 도트로 = 약 30x78도트(지금 38x97의 0.8배), PPU 80 x 배율 5.
     - 0.8배로 줄여 다시 그려야 해서 1텍셀 선(지붕 레일·외곽선·라이트)을 손으로 다시 정리해야 함. 시트의 RV_2 조각 크기·피벗(meta) 또는 별도 PNG가 바뀜.
     - 충돌체·트럭 크기·맵 결과·상호작용 거리 그대로. CC BY라 수정 가능(저작자 표시 + 수정 사실).
  C. 그대로 두기(4.8px) - 바뀌는 것 없음.
