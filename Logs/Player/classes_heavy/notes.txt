[문제] 스카우트만 시안 B(둥근 몸통, 그늘 2겹, 손 3x3을 몸에 붙임, 그림자 없음)로 바뀌어 다른 클래스로 하면 이질감이 든다.
  스카우트가 트래퍼보다 커야 하는데, 지금 두 몸통 지름은 같고(13도트) 트래퍼는 꽉 찬 진한 갈색 + 충돌체가 더 커서 더 커 보인다.

[지금 크기] 1080p, 카메라 5.6 기준. 네 클래스 모두 도트 1개 = 1/16칸 = 6.0px(배율 / PPU가 모두 0.0625).
  클래스      몸통 지름        클래스 배율  PPU     충돌체(1x1 상자 x 배율)
  스카우트    13도트 = 78px    0.64        10.24   0.64칸 = 62px
  트래퍼      13도트 = 78px    0.72        11.52   0.72칸 = 69px
  거너        11도트 = 66px    0.64        10.24   0.64칸 = 62px
  무장 거너   11도트 = 66px    0.826       13.216  0.826칸 = 80px (총 포함 폭 16도트)

[시안 크기] 클래스 배율·충돌체·PPU·피벗은 그대로, 그림의 몸통 도트 수로만 조정.
  스카우트 13(그대로) > 트래퍼 11(13에서 줄임) = 거너 11 = 무장 거너 11(+총).

[같은 규칙] 스카우트 시안 B에서 그대로 가져옴 - 같은 규칙으로 스카우트 B를 다시 그리면 원본과 0칸 차이.
- 몸통: 둥근 실루엣(행 폭이 끝에서 5칸부터 2씩 늘어 지름까지), 바깥부터 외곽선 #2F2F2E → 진한 그늘(바탕색 x 0.71) → 연한 그늘(x 0.863) → 바탕색.
  0.71·0.863은 스카우트 #FFFFFF → #DCDCDC → #B5B5B5와 같은 밝기 비율. 그늘은 테(동심원)라 몸이 돌아도 빛 방향이 같이 돌지 않는다.
- 손: 안쪽 3x3(바깥 줄은 손 색 x 0.863) + 외곽선, 몸 오른쪽 위·아래 대각선에 반쯤 걸쳐 붙임(떠 있는 틈 없음).
- 캔버스 20x20, 몸통 가운데 픽셀 (9,10) - 지금 그림과 같다. 그림자는 넣지 않음(스카우트와 같음). 반투명 없음.
