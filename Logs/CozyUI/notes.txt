[1. 색·필터 보정안] 모양·크기·도트·반투명 가장자리 그대로. 픽셀마다 HSV 채도에만 같은 배율을 곱함(색조·명도·알파 그대로).
  채도 목표 = (지금 채도 + 캐릭터 기준 0.26) / 2 - UI라 캐릭터 기준까지는 내리지 않음.
  채도 = 칠한 색(가장자리에서 가장 많은 색·V<0.25·알파<128 제외)의 픽셀 평균. 색 수 = 투명이 아닌 서로 다른 RGBA 색.

  IconsDefault19_64px (65x69) | 보호소 아이템 상점 "마취총 재장전" 줄 아이콘(65x65px) | 0.616 → 0.437 (x0.71) | 75 → 75 | Bilinear → Point
  ItemSlot1 (137x148) | 마을·트럭 인벤토리 바 기본 칸(141x141px) | 0.574 → 0.417 (x0.73) | 169 → 169 | Point 그대로
  ItemSlotSelected1 (138x148) | 인벤토리 바 선택된 칸 | 0.177 → 0.147 | 173 → 173 | Point 그대로
    선택 칸은 이미 0.26보다 낮지만 나무 테두리가 기본 칸과 같은 그림이라, 채도 0.3 이상인 테두리 픽셀에만 기본 칸과 같은 배율(x0.726)을 곱함
    (크림색 안쪽은 그대로) → 칸을 고를 때 테두리 색이 바뀌어 보이지 않음(두 칸 테두리 주요 색 #976456로 같음).
  외곽선(가장자리에서 가장 많은 색): 버튼·칸 #97513E → #976052/#976456, 아이콘 #18AB2E → #42AB52. 게임 외곽선 #2F2F2E로 바꾸지는 않음(UI 스타일 유지).
  적용할 때 바꿀 설정: IconsDefault19_64px.png.meta filterMode 1 → 0. 나머지 그림은 png만 교체(meta 그대로).
  참고: 4개 모두 meta 압축이 켜져 있음(textureCompression 1). 이번 비교 렌더도 압축 켠 상태 그대로임.

[2. UI 도트 크기 - 방법만 정리] (고르지 않음, 적용하지 않음)
  지금: 버튼 화면 도트 1.2px(그림 2텍셀 묶음 x 0.6px), 아이콘 1.0px, 칸 1.0px. 게임 그림 6px, 상점 패시브 아이콘 보정안 약 5.9px.
  UI 배율은 화면 크기에 따라 바뀜(1080p 0.857, 1440p 1.143) → 어떤 도트 크기든 정수 배가 아니면 도트 폭이 고르지 않게 보일 수 있음.
  A. 그대로 1px(지금) - 매끈한 UI 스타일. 글씨(TMP, 매끈한 폰트)와는 잘 어울리지만 게임 그림(6px)과는 질감이 다름. 바꿀 것 없음.
  B. 3px 안팎(게임 그림의 절반, UI에서 흔한 중간값)으로 다시 찍기
     - UI 크기 그대로: 배지 217x96px → 약 72x32도트, 칸 141px → 약 47도트, 아이콘 65px → 약 22도트.
     - 테두리·둥근 모서리 정도는 살릴 수 있고 글씨와도 크게 어긋나지 않음. 그림은 다시 찍어야 함(수정 허용 라이선스). 반투명 가장자리는 없애야 함.
  C. 6px(게임 그림과 같게)로 다시 찍기
     - UI 크기 그대로: 배지 약 36x16도트, 칸 약 24도트, 아이콘 약 11도트(패시브 아이콘 보정안과 같은 굵기).
     - 게임 화면과 질감은 같아지지만 칸·배지가 아주 투박해지고, 그 안의 매끈한 글씨(칸 번호·마일리지 숫자)와 차이가 커짐 → 픽셀 폰트를 같이 검토해야 할 수 있음. 다시 찍어야 함.
  D. 지금 그림을 최근접 축소로 자동 변환(1/3이면 약 3px) - 빠르지만 1텍셀 선·안티앨리어싱이 뭉개져 손질이 필요함. UI 크기 그대로.
  UI 자체를 키워서 도트를 키우는 방법은 6px까지 가려면 5~6배로 커져야 해서 현실적이지 않음(3px도 약 3배).
